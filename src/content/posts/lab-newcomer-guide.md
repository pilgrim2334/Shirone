刚进实验室时，我一边听师兄讲，一边记录操作。笔记里常常上一句还是怎么找枪头，下一句已经变成了培养基用量。于是我想把这些内容慢慢整理在这里，让后来的人能更快知道：东西在哪里、操作前要准备什么、做完以后如何收尾。

这是一份持续更新的学习指南。已经明确的内容直接记录；没听清、不同版本有冲突的地方保留为待确认项。第一次使用设备仍需由熟悉设备的人带教，具体操作以实验室确认的流程为准。

## 第一天先弄清楚的事

- 找到带教人员，了解哪些仪器需要培训、预约或登记后才能使用。
- 请带教人员带着走一遍实验区，确认个人物品、清洁耗材、试剂和废物各自放在哪里。
- 确认紧急出口、应急用品及异常情况的报告方式；具体位置在现场核实后补记。
- 了解公共试剂和其他人的物品如何借用。笔记里的提醒是：隔壁台子的物品使用前先询问。
- 分清自己的样品与公共库存，知道培养皿、离心管和培养基应如何标记。

### 每台设备后续怎么补

建议每台设备保留一份简短说明：

1. **实物照片与名称**：型号和辨认特征，避免同类设备认错。
2. **位置**：房间、区域、柜架层位或明显参照物。
3. **使用入口**：是否需要预约、登记或带教。
4. **操作资料**：说明书和已核定Protocol链接。
5. **结束检查**：清洁、归位、记录，以及是否关机。
6. **常见异常**：遇到问题先找谁、哪些情况需要停止操作。

设备故障或样品异常直接联系现场负责人，不依赖博客评论处理。

## 一次操作的完整顺序

### 操作前：先看细胞，再准备物品

显微镜下观察细胞形态、贴壁、融合度及异常漂浮物，再决定本次是观察、换液还是传代。准备对应试剂、枪头、离心管和培养皿，并提前写好标签。

进入操作区域前，按实验室流程处理工作台和物品外表面。区分清洁物品、正在使用的物品和废物，避免操作中来回寻找耗材。

### 操作中：把流程和参数分开记

- **换液流程**：观察 → 吸旧液 → 按确认方案决定是否PBS清洗 → 沿壁加新鲜培养基 → 轻晃 → 放回培养箱。
- **传代流程**：观察 → 吸旧液 → PBS清洗 → 胰酶消化并观察终点 → 终止消化 → 收集离心 → 重悬 → 按计划接种 → 继续培养。
- **操作提醒**：吸液和加液避免冲击细胞层；吹打轻柔，减少气泡；不同样品间更换相应耗材；酒精不喷入培养皿或培养液。

上述只是流程导航。详细步骤见[细胞培养Protocol](/posts/adherent-cell-culture-protocol/)，使用前核对对应细胞和器皿参数。

### 操作后：归位与记录也是实验的一部分

培养物放回对应位置，记录日期、代次、实际操作、试剂批次及偏离原流程的情况。废液和耗材放入实验室指定收集处，按规定处理并清洁归位。涉及病毒的耗材按照对应专门要求处理。

笔记中的“废液加84”没有完整浓度和作用时间，暂不作为可直接执行的废液处理流程。

## 耗材准备和灭菌笔记

- 灭菌前注明物品名称、姓名和时间，按要求包装并使用过程指示标识。
- 玻璃瓶高压灭菌时瓶盖处理、包装方式和程序需由负责人员确认。
- 笔记记录了灭菌指示胶带颜色变化；颜色只是过程信息，不单独等同于灭菌效果合格。
- 装枪头时确认规格和方向。机器卡住先停止，具体处理按设备要求执行。
- 灭菌后物品的烘干、保存和有效期仍需补齐实验室规定。

## 培养基与试剂管理

笔记中的完全培养基组成为DMEM、FBS及1× P/S双抗。每次配制应写明基础培养基型号、最终比例、添加物、配制日期和操作者，并记录批次。

配液计算要分清“加入多少”和“最终总体积”。例如50 mL的10× PBS需补水至500 mL，才能得到1× PBS；不能把“50 mL储备液＋400 mL水”标成1×。血清和双抗也按最终体积核算。

支原体相关试剂的产品名称和加样参数尚未辨认清楚，先保留为待核实内容，不并入日常培养基配方。
